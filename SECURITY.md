# Security Policy

## Supported Versions

The Crime Intelligence Platform actively receives security updates and patches on the latest main branch.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is paramount for law enforcement data management systems. If you discover a security vulnerability within CrimeIntel, please report it responsibly:

1. **Do NOT** open a public issue on GitHub.
2. Email your detailed findings to security@crimeintel.local or submit via confidential disclosure.
3. Include clear steps to reproduce, potential impact assessment, and proof of concept if applicable.

We aim to acknowledge receipt of vulnerability reports within 24-48 hours and provide estimated fix timelines promptly.
