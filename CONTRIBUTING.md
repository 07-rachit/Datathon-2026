# Contributing Guidelines

Thank you for your interest in contributing to the **Crime Intelligence Platform (CrimeIntel)**.

## Code Standards

- **Backend (Python / FastAPI)**: Follow PEP 8 style guidelines. Ensure type annotations are used where appropriate and tests pass cleanly using `pytest`.
- **Frontend (React / Vite)**: Follow component modularization principles, keep JSX clean, and adhere to Tailwind / vanilla CSS styling guidelines.

## Development Workflow

1. Fork the repository and create a feature branch (`git checkout -b feature/my-feature`).
2. Implement your changes in atomic, well-tested commits.
3. Ensure the test suite passes locally (`pytest tests/`).
4. Push to your branch and submit a Pull Request.

## Pull Request Checklist

- [ ] Code follows existing formatting and style conventions.
- [ ] New functionality includes corresponding unit tests.
- [ ] No sensitive credentials or secrets are committed.
- [ ] Documentation and inline comments are updated where relevant.
